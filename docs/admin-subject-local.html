Local administrator setup

Open this file locally on your computer. No network requests or storage are used. Enter the same project and SUBJECT_SECRET used by your Worker.

For a new administrator only: run this SQL in the private D1 Console. Then add the identifier as a child of adminAllowlist in Firebase, with the boolean value true. This identifier is not a login token. Keep it private to avoid exposing allowlist information.

For removal or re-enabling an existing administrator, use the private setup CLI: existing sessions must also be revoked.

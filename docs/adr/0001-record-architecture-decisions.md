# 1. Record architecture decisions

Date: 2026-11-10

## Status
Accepted

## Context
Bricks is developed by several AI agents and tools over many sessions. Decisions
were spread across the spec, handover and progress log, which makes the reasons
behind them hard to find.

## Decision
Record significant decisions as numbered ADRs in `docs/adr/`.

## Consequences
New agents can read why things are the way they are. Each ADR is short; details
stay in the linked docs.
